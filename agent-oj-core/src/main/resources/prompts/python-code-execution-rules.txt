# 代码编写约束

这段规则用于约束 Agent 在调用 `execute_python_code` 工具时生成 `code` 字段的内容。
目标是生成可被执行器直接拼接并调用的 Python 函数源码，而不是完整脚本、类或带说明的 markdown 内容。

## 必须遵守的规则

1. `code` 必须是可直接执行的 Python 代码，且核心内容必须是顶层函数定义。
2. 必须生成 `def` 函数，函数名必须与传入的 `functionName` 完全一致，包括大小写。
3. 函数形参名必须与 `testInputs` 中提供的 key 一一对应，因为执行器会按命名参数方式调用函数。
4. 除非确有必要，不要写顶层 `import`；如果必须导入，只允许少量标准库导入。
5. 不要生成 class、`if __name__ == "__main__":`、脚本式主流程、示例调用、测试调用或打印最终结果的顶层代码。
6. 函数必须通过 `return` 返回最终结果，不要只使用 `print` 输出结果。
7. 函数的所有可达执行路径都必须返回值；除非题目期望输出明确是 `None`，否则禁止隐式返回 `None`。
8. 返回值应尽量简单、稳定、可预测，优先使用 `int`、`float`、`str`、`bool`、`list`、`dict`、`None` 等基础类型或常见容器。
9. 若题目要求“原地修改（in-place）”，也必须 `return` 修改后的对象（如 `return nums`），以便执行器通过 `_result` 获取可校验结果。
10. 必须使用合法 Python 语法：字符串要正确加引号，布尔值使用 `True` / `False`，空值使用 `None`，列表和字典字面量必须合法，缩进必须一致。
11. 不要输出 markdown 代码块标记（如 ```python）、解释文字、前后缀说明或任何非代码文本。
12. 不要依赖命令行参数、标准输入、交互输入、本地文件、网络请求、外部进程或项目外部自定义环境。
13. 不要返回自定义类实例、生成器、打开的文件对象或其他不稳定、难以序列化的结果。
14. 不要生成多个候选函数、多个同名函数，或把主要答案写在函数外部变量中。
15. 当 `testInputs` 中某个输入值是字符串时，执行入口必须按 Python 字符串字面量处理，并使用单引号包裹（如 `text='hello'`），避免被解释为变量名。
16. `testInputs` 中的数组/对象必须保持结构化类型，不要把整个数组或对象写成一个字符串（例如不要把 `["a", "b"]` 写成 `"['a','b']"`）。
17. 如果参数是 `list[str]` 或嵌套字符串容器，只给叶子字符串元素加单引号，容器本身仍是 Python 列表/字典字面量。
18. 当参数名属于链表语义（`head` / `headA` / `headB` / `list1` / `list2` / `l1` / `l2`）时，执行器会提供节点语义对象，应按 `.val` / `.next` 访问，不要按数组下标处理。
19. 这类链表参数无需自行定义 `ListNode` / `TreeNode` 类；直接操作传入节点对象即可。若题目要求返回节点，请返回节点对象或 `None`。
20. 非链表参数仍按 JSON 原结构处理，禁止把数组/对象整体写成字符串。

## 执行器调用方式说明

执行器会在你生成的函数代码后自动追加入口调用，等价于：

`_result = functionName(key1=value1, key2=value2, ...)`

因此必须确保：

- 函数名与 `functionName` 完全一致。
- 形参名与 `testInputs` 的 key 完全一致。
- `testInputs` 的字符串值在入口调用时必须是单引号字面量（例如 `name='alice'`）。
- 若 `testInputs` 包含字符串数组，调用形态应为 `strs=['eat', 'tea']`，而不是 `strs="['eat','tea']"`。
- 执行器最终只读取 `_result` 作为判题结果，因此函数必须显式返回可比较结果，不能依赖副作用。
- 函数可以直接通过命名参数调用。
- 不要自己再写调用入口、样例执行或最终输出代码。

## 禁止事项

- 不要生成 `class Solution`、`class Main` 等类封装。
- 不要生成 `main()` 或 `if __name__ == "__main__":`。
- 不要在函数外层调用函数。
- 不要只 `print` 不 `return`。
- 不要写“只原地修改但不返回值”的函数（例如 `moveZeroes(nums)` 修改完 `nums` 后没有 `return nums`）。
- 不要使用与输入 key 不一致的形参名。
- 不要混入 Java、JavaScript 或其他语言语法。
- 不要输出注释性说明文字、题解说明、自然语言解释。

## 示例

### 示例 1：代码形态

正确：

```python
def solve(nums):
    return sum(nums)
```

错误：

```python
class Solution:
    def solve(self, nums):
        return sum(nums)

print(Solution().solve([1, 2, 3]))
```

### 示例 2：参数名映射

假设 `functionName = "add"`，且 `testInputs` 中的 key 为 `a`、`b`。

正确：

```python
def add(a, b):
    return a + b
```

错误：

```python
def add(x, y):
    return x + y
```

### 示例 3：返回值与语法

正确：

```python
def parse_flag(text):
    if text == "yes":
        return {"ok": True, "value": text}
    return {"ok": False, "value": None}
```

错误：

```python
def parse_flag(text):
    if text == "yes":
        print("ok")
    return {ok: true, value: null}
```

### 示例 4：字符串 `testInputs` 引号规范

假设 `functionName = "normalize"`，且某条 `testInputs` 为 `{"text": "'hello'"}`。

正确（执行器拼接调用等价于）：

```python
_result = normalize(text='hello')
```

错误（会把 `hello` 当变量名）：

```python
_result = normalize(text=hello)
```

### 示例 5：字符串数组参数类型规范

假设 `functionName = "groupAnagrams"`，且某条 `testInputs` 为 `{"strs": ["'abc'", "'bca'", "'cab'"]}`。

正确（执行器拼接调用等价于）：

```python
_result = groupAnagrams(strs=['abc', 'bca', 'cab'])
```

错误（把整个数组变成字符串）：

```python
_result = groupAnagrams(strs="['abc','bca','cab']")
```

### 示例 6：与 `expectedOutput` 的格式对齐（题目生成场景）

当函数返回“包含字符串的列表/字典”时，执行器通常得到 Python 字面量字符串，例如：

```python
_result = groupAnagrams(strs=['eat', 'tea'])
# _result 可能表现为: "[['eat', 'tea']]"
```

因此在题目生成阶段，对应测试用例应写为：

```json
{
  "expectedOutput": "[['eat', 'tea']]"
}
```

### 示例 7：原地修改题必须返回结果（避免无返回值导致判题失败）

假设 `functionName = "moveZeroes"`，且某条 `testInputs` 为 `{"nums": [0, 1, 0, 3, 12]}`，期望输出为 `[1, 3, 12, 0, 0]`。

正确：

```python
def moveZeroes(nums):
    left = 0
    for right in range(len(nums)):
        if nums[right] != 0:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
    return nums
```

错误（只修改不返回，会导致 `_result` 不可用于正确判题）：

```python
def moveZeroes(nums):
    left = 0
    for right in range(len(nums)):
        if nums[right] != 0:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
```
