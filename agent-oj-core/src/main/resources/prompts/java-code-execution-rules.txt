# Java 代码编写约束

这段规则用于约束 Agent 在调用 `execute_python_code` 工具且 `language=java` 时生成内容。

目标是同时生成：
1. `referenceAnswer`：可被执行器直接编译、反射调用并通过测试的 Java 代码。
2. `codeSkeleton`：提供给用户提交代码时使用的框架（模板），不是标准答案。

## 必须遵守的规则

1. `functionName` 必须与 `referenceAnswer` 和 `codeSkeleton` 中的目标方法名完全一致（大小写一致）。
2. `referenceAnswer` 必须能单独编译执行：语法合法、类型合法、所有可达路径显式 `return`（除非题目明确需要 `void`）。
3. 若题目为“原地修改（in-place）”类题目，仍需返回修改后的对象（如 `return nums;`），避免判题拿不到结果。
4. 方法参数个数与顺序必须严格匹配 `testInputs` 中该测试用例对象的 key 顺序；不要自行调整参数顺序。
5. 不要写同名重载方法。执行器按“方法名 + 参数个数”反射匹配，同名重载会引发命中不确定。
6. `referenceAnswer` 可写“方法体片段”或“完整类”，但必须确保目标方法可被反射调用。
7. 只使用 JDK 标准库；禁止第三方依赖。
8. 返回值必须稳定且可序列化，优先使用 `int/long/double/boolean/String`、数组、`List`、`Map`、`null`。
9. 不要返回自定义对象实例、流、迭代器、线程、文件句柄等不稳定结果。
10. 不要依赖命令行参数、标准输入、文件系统、网络请求、数据库、外部进程或随机副作用。
11. 不要生成 `main`、样例调用、打印最终结果等入口逻辑；不要把答案写在方法外部执行代码中。
12. 不要输出 markdown 代码块标记（如 ```java）或解释性自然语言，只输出纯代码文本。
13. `codeSkeleton` 必须是“给用户填写”的框架：仅保留方法签名 + 空方法体 `{}`，不得包含完整算法细节，不得包含任何注释、占位返回或实现语句。
14. `codeSkeleton` 与 `referenceAnswer` 必须在方法签名上完全相同。
15. `referenceAnswer` 是系统用于执行校验的标准答案，必须完整、正确、可运行。
16. 当参数名属于链表语义（`head` / `headA` / `headB` / `list1` / `list2` / `l1` / `l2`）时，执行器会把数组样例归一化为链表节点；实现应按 `ListNode` 语义处理（`.val` / `.next`），不要按数组处理。
17. 对返回链表节点的题型（如相交链表），方法应返回节点引用；无交点返回 `null`，不要改成返回节点值或 `-1`。
18. 非链表参数仍按 JSON 结构声明类型（数组用数组/`List`，对象用 `Map` 或明确结构），不要把数组/对象当字符串处理。

## 执行器调用方式说明（务必理解）

Java 执行器行为要点：

- 若你只输出方法片段，执行器会自动包装为：
  `public class UserSolution { ...你的方法... }`
- 执行器通过反射调用目标方法，参数来自 `testInputs`，调用顺序等价于：
  `functionName(arg1, arg2, ...);`
  其中 `arg1/arg2/...` 来自 `testInputs` 对象的 values 顺序。
- 判题依赖方法返回值进行比较；仅有副作用但没有返回值的写法会导致判题失败或不稳定。

## 禁止事项

- 不要输出多个候选解法（例如“解法1/解法2”同时存在）。
- 不要输出多个同名目标方法。
- 不要输出 `package` + 多文件依赖结构（保持单段可编译代码）。
- 不要把数组或对象参数当作字符串处理（例如把 `[1,2,3]` 当成 `"[1,2,3]"`）。
- 不要混入 Python / JavaScript 语法。

## Few-shot 示例

### 示例 1：代码形态

正确（可执行方法）：

```java
public int sum(int[] nums) {
    int total = 0;
    for (int num : nums) {
        total += num;
    }
    return total;
}
```

错误（包含入口执行代码）：

```java
public int sum(int[] nums) {
    int total = 0;
    for (int num : nums) {
        total += num;
    }
    return total;
}

public static void main(String[] args) {
    System.out.println(new UserSolution().sum(new int[]{1, 2, 3}));
}
```

### 示例 2：参数顺序必须匹配 `testInputs`

假设 `functionName = "twoSum"`，某条 `testInputs` 为：
`{"nums":[2,7,11,15],"target":9}`

正确：

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) {
            return new int[]{map.get(need), i};
        }
        map.put(nums[i], i);
    }
    return new int[0];
}
```

错误（参数顺序颠倒）：

```java
public int[] twoSum(int target, int[] nums) {
    return new int[0];
}
```

### 示例 3：原地修改题也必须返回结果

正确：

```java
public int[] moveZeroes(int[] nums) {
    int insert = 0;
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] != 0) {
            int tmp = nums[insert];
            nums[insert] = nums[i];
            nums[i] = tmp;
            insert++;
        }
    }
    return nums;
}
```

错误（仅修改不返回）：

```java
public void moveZeroes(int[] nums) {
    int insert = 0;
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] != 0) {
            int tmp = nums[insert];
            nums[insert] = nums[i];
            nums[i] = tmp;
            insert++;
        }
    }
}
```

### 示例 4：`codeSkeleton` 与 `referenceAnswer` 的关系

正确（`codeSkeleton` 是用户模板，不是答案）：

```json
{
  "functionName": "maxSubArray",
  "codeSkeleton": "public int maxSubArray(int[] nums) {\\n    }",
  "referenceAnswer": "public int maxSubArray(int[] nums) {\\n    int best = nums[0], cur = nums[0];\\n    for (int i = 1; i < nums.length; i++) {\\n        cur = Math.max(nums[i], cur + nums[i]);\\n        best = Math.max(best, cur);\\n    }\\n    return best;\\n}"
}
```

错误（`codeSkeleton` 与 `referenceAnswer` 完全相同）：

```json
{
  "functionName": "maxSubArray",
  "codeSkeleton": "public int maxSubArray(int[] nums) {\\n    int best = nums[0], cur = nums[0];\\n    for (int i = 1; i < nums.length; i++) {\\n        cur = Math.max(nums[i], cur + nums[i]);\\n        best = Math.max(best, cur);\\n    }\\n    return best;\\n}",
  "referenceAnswer": "public int maxSubArray(int[] nums) {\\n    int best = nums[0], cur = nums[0];\\n    for (int i = 1; i < nums.length; i++) {\\n        cur = Math.max(nums[i], cur + nums[i]);\\n        best = Math.max(best, cur);\\n    }\\n    return best;\\n}"
}
```

### 示例 5：返回类型要可比较、可序列化

正确：

```java
public List<Integer> plusOne(List<Integer> digits) {
    List<Integer> result = new ArrayList<>(digits);
    for (int i = result.size() - 1; i >= 0; i--) {
        int sum = result.get(i) + 1;
        result.set(i, sum % 10);
        if (sum < 10) {
            return result;
        }
    }
    result.add(0, 1);
    return result;
}
```

错误（返回自定义对象，判题不稳定）：

```java
class Node {
    int value;
    Node(int value) {
        this.value = value;
    }
}

public Node plusOne(List<Integer> digits) {
    return new Node(1);
}
```
