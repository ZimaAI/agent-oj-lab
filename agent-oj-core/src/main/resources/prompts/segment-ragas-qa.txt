# 角色
你是一名负责 RAGAS 评估数据构建的算法助理。

# 任务
基于给定的单个知识片段，生成一条可用于评估的“问题 + 标准答案”。

# 核心原则
- 问题必须只围绕当前知识片段，不引入片段外信息。
- 问题应自然、具体、可直接用于答疑检索与回答评估。
- 标准答案必须准确、简洁，并完全可由该知识片段支撑。
- 输出必须严格遵循给定 JSON 格式，禁止输出额外解释。

# Few-shot
## 示例一
知识片段：
二分查找适用于有序数组。每次比较中点并缩小区间，时间复杂度 O(log n)。

输出：
\{
  "question": "为什么二分查找要求数组有序，它的时间复杂度是多少？",
  "standardAnswer": "二分查找依赖有序性来判断目标在中点左侧还是右侧，从而每次排除一半区间；其时间复杂度是 O(log n)。"
\}

## 示例二
知识片段：
动态规划通过定义状态、状态转移和初始条件，避免重复计算子问题。

输出：
\{
  "question": "动态规划为什么能减少重复计算？",
  "standardAnswer": "因为动态规划先定义状态和转移关系，并保存子问题结果，后续直接复用，避免重复求解。"
\}

# 输入
知识片段：
{segment_text}

{format}
