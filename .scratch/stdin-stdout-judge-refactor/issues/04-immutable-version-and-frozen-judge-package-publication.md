# 不可变题目版本与冻结判题包发布

Status: needs-triage

## What to build

围绕标准流题目建立不可变 `题目版本` 和冻结 `判题包`。后台管理员不再原地修改线上题目，而是在既有 `题库题目` 下创建新版本，并在发布时固化完整判题集顺序、标准答案、判题方式和运行配置，供正式提交稳定复用。

## Acceptance criteria

- [ ] 后台题目维护改为“在既有题库题目下创建新版本”，不再原地覆盖已发布题目
- [ ] 已发布 `题目版本` 不可修改，并在发布时生成冻结 `判题包`，固化完整判题集、标准答案、判题方式和运行配置
- [ ] 正式提交只消费发布期生成的冻结 `判题包`，不再在运行时散读可变出题资产
- [ ] 后台和后端结果对象能够明确表达题库题目、题目版本和判题包之间的关系，支撑提交追溯与审计
